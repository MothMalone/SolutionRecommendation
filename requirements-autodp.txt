# BE / FE / CBE encoders, but the package's own metadata never lists it. Without it those encoders

# the root, and the search silently returns an EMPTY pipeline -- i.e. the raw dataset -- on almost
# every dataset. That failure is indistinguishable from honest convergence unless you instrument the
# search. Installing it is required to evaluate AutoDP fairly.
